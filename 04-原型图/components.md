# 组件规范

## 按钮
- 主按钮：背景 #19324A，白字，padding 7px 14px，圆角 5px，hover #22415C
- 次级按钮：白底 + 1px #B9C6D1 描边 + 主色文字
- 危险按钮：白底 + 1px #B02A37 描边 + 危险色文字
- 小尺寸：padding 3px 9px，字号 12px（仅表格行内）

## 表单
- 标签宽度 100–120px，右对齐；控件高度 32px
- 必填标记前置红色 *；错误提示在控件下方 11.5px 危险色
- 下拉框宽度 180–240px；日期区间 240px；长文本域满宽
- 新增/编辑使用独立页或右侧抽屉，关闭前检测未保存内容

## 表格
- 表头背景 #EEF2F5，字号 12.5px，行高 40px
- 表头不写死宽度，按内容自适应并设最小宽度，允许横向滚动
- 编号/状态/日期/操作列单行不换行
- 空状态：说明原因 + 下一步操作（清空筛选 / 新建）

## 标签
- 高度 20px，圆角 10px，padding 1px 8px，1px 描边 + 浅底
- 五类语义见 design-system.md 状态标签

## 卡片
- 白底，1px #E2E7EC，圆角 8px，padding 16px，卡片间距 16px
- 指标卡：标题 12px 次要色，数值 22px 主色 600

## 分页
- 右对齐，页码按钮 4px 圆角，当前页主色填充
- 显示总数、上一页/下一页、页码、每页条数选择

## 弹窗与抽屉
- 抽屉宽 480px（审批类 560px），从右侧滑入，仅此类使用阴影 0 8px 24px rgba(25,50,74,.16)
- 底部固定操作区：取消（次级）+ 确认（主按钮）；危险操作确认按钮用危险色

## 时间轴
- 左侧 1px 竖线 + 7px 圆点，事件标题 12.5px 600，时间与操作人 11.5px 次要色
