# 设计系统 · 乐器租赁与维修工单管理系统

数据钢蓝风格：以可读性、操作效率与状态辨识为核心，不使用装饰性光效与巨幅插画。

## 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | #19324A | 顶部栏、侧边栏、主按钮、关键数字 |
| 辅助色 | #356A7A | 次级按钮、筛选选中态、普通图表系列 |
| 强调色 | #456C7E | 链接、信息提示、图表对比系列 |
| 页面背景 | #F4F6F8 | 主内容区 |
| 容器 | #FFFFFF | 表格与表单容器，1px #E2E7EC 描边 |
| 成功 | #2B7955 | 已完成 / 已通过 / 可租 |
| 危险 | #B02A37 | 驳回 / 逾期 / 异常 / 删除，仅小面积 |
| 中性 | #63707E | 次要文字、辅助说明 |

图表色：主色、辅助色、强调色与中性灰派生；同一含义跨页面保持一致。状态不以颜色单独表达，必须同时有中文标签。

## 字体阶梯

- 页面标题 17px / 600
- 卡片标题 13px / 600
- 正文 13px / 400
- 表格 12.5px，数字列启用 tabular-nums
- 辅助说明 11.5px / #63707E

## 骨架与间距

- 侧栏 220px（折叠保留图标与悬浮说明）、顶栏 56px、内容区 padding 24px
- 卡片圆角 8px，表格/输入框圆角 5px；阴影仅用于抽屉与弹窗
- 筛选区、表格区、详情区边界清晰；常用操作不超过三级层级
- 表单标签 100–120px，单列输入 360–520px，搜索下拉 180–240px

## 状态标签

| 语义 | 样式 | 示例 |
|---|---|---|
| 进行/信息 | 蓝底 #EFF6F8 + #356A7A | 待押金、租用中 |
| 成功 | 绿底 #EDF7F1 + #2B7955 | 可租、已完成 |
| 危险 | 红底 #FBEDEE + #B02A37 | 逾期、待归还验收 |
| 等待 | 琥珀底 #FBF5E8 + #8A5B10 | 待审核、待交接 |
| 中性 | 灰底 #F3F5F7 + #5D6B79 | 保养中、已归档 |

## 交互约定

- 表格行内最多「查看 + 2 个高频操作」，其余进「更多」
- 审批/流转使用抽屉，抽屉内展示单据摘要
- 危险操作红色描边 + 二次确认；普通取消不加强提醒
- 列表服务端分页（10/20/50），切换筛选回到第 1 页
- 加载超过 300ms 显示骨架或表格 loading，禁止整页白屏
- 低于 768px 侧栏转抽屉，表格转信息卡片
